## ⚡ Por que o DLuz ZArchiver foi criado?

Geralmente, emuladores Android (BlueStacks, MSI App Player, LDPlayer, etc.) não aceitam arquivos de pacotes divididos (**APKS / Split APKs**) por arrastar e soltar comum. Para instalar, os jogadores eram obrigados a:
1. Instalar o aplicativo ZArchiver dentro do emulador Android.
2. Copiar manualmente arquivos pesados (300MB ~ 1GB) para a memória interna do emulador.
3. Abrir o ZArchiver no emulador, localizar o arquivo, autorizar permissões e aguardar.

Com o **DLuz ZArchiver**, tudo isso é feito em **1 clique** diretamente pelo Windows via **ADB nativo**!

---

## 🚀 Funcionalidades Principais

- **🔥 Suporte Completo a Free Fire V7A:** Detecta e instala automaticamente a versão otimizada ARMv7a com 1 clique.
- **📦 Instalador Universal de Splits:** Descompacta e instala automaticamente qualquer arquivo `.apks`, `.xapk`, `.apk` ou `.zip`.
- **📂 Suporte Automático a OBB (XAPK):** Detecta pastas e arquivos `.obb` e transfere para `/sdcard/Android/obb/<pacote>/` antes de instalar os splits.
- **🔌 Detecção Automática de Emuladores:** Identifica BlueStacks 5/NXT, MSI App Player, LDPlayer, Nox, SmartGaga e celulares via cabo USB ou Wi-Fi.
- **🛡️ ADB Embutido e Portátil:** Funciona imediatamente em qualquer computador, sem necessidade de instalar Android SDK ou configurar variáveis de ambiente.
- **🎨 Interface Moderna Google Stitch:** Visual Gamer Dark com tema obsidian, console de telemetria em tempo real, barra de progresso e sons táteis.

## 🎮 Como Usar

1. Abra seu emulador Android favorito (BlueStacks, LDPlayer, etc.).
2. Execute o **DLuzZArchiver.exe**.
3. O aplicativo identificará seu emulador automaticamente no canto superior direito.
4. Para o Free Fire V7A: clique no botão verde **"⚡ INSTALAR FREE FIRE V7A NO EMULADOR"**.
5. Para outros jogos: arraste o arquivo `.apks`, `.xapk` ou `.apk` para dentro da janela ou clique em "Escolher Arquivo".
6. Aguarde a barra de progresso no console finalizar e divirta-se!
